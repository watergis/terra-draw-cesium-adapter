# Website

The website for [`@watergis/terra-draw-cesium-adapter`](../packages/terra-draw-cesium-adapter), a Cesium flavoured take on [terradraw.io](https://terradraw.io).

## Commands

Run these from the repository root.

| Command           | Description                               |
| ----------------- | ----------------------------------------- |
| `pnpm docs:dev`   | Run the website at http://localhost:5173  |
| `pnpm docs:build` | Build the website, API docs and Storybook |

## What gets built

`pnpm docs:build` writes everything a single Cloudflare Worker serves as static assets to `docs/dist`:

| Path          | Content                                                              |
| ------------- | -------------------------------------------------------------------- |
| `/`           | The demo, a Preact app routed on the URL hash                        |
| `/api/`       | The adapter's API docs, generated by [TypeDoc](https://typedoc.org/) |
| `/storybook/` | The built [Storybook](../packages/storybook)                         |
| `/cesium/`    | Cesium's static assets, shared by the demo and the Storybook stories |

## Previewing the deployed site

`pnpm docs:dev` only runs the demo, so the API Docs and Storybook tabs are empty until `pnpm docs:build` has produced them. To preview the whole site exactly as it is deployed, build it and serve it through Wrangler:

```bash
pnpm docs:build
pnpm exec wrangler dev
```

## Deployment

The Worker is configured in [`wrangler.jsonc`](../wrangler.jsonc) and deployed by Cloudflare Workers Builds, with `pnpm docs:build` as its build command.

## Cesium Ion access token

Like the [Storybook stories](../packages/storybook/README.md#cesium-ion-access-token), the demo falls back to Cesium's bundled offline imagery without a Cesium Ion access token. To use Cesium World Imagery and Cesium World Terrain instead, copy [`.env.example`](./.env.example) to `.env` and fill in `CESIUM_ION_ACCESS_TOKEN`:

```bash
cp docs/.env.example docs/.env
```

The token is inlined into the client bundle, so restrict it to the URLs the website is served from.
